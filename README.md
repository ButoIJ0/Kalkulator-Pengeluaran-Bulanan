eskripsi

Aplikasi Perhitungan Pengeluaran Mahasiswa adalah aplikasi sederhana yang dibuat untuk membantu mahasiswa mencatat dan menghitung pengeluaran bulanan. Aplikasi ini memungkinkan pengguna untuk memasukkan uang bulanan, mencatat setiap pengeluaran, serta melihat total pengeluaran dan sisa uang secara otomatis. Dengan adanya aplikasi ini, mahasiswa diharapkan dapat lebih memahami pola pengeluaran dan mengelola keuangan dengan lebih baik.

Aplikasi ini dikembangkan sebagai bagian dari Tugas Besar Praktikum Logika Pemrograman dengan menerapkan konsep logika pemrograman pada permasalahan yang dekat dengan kehidupan sehari-hari mahasiswa.

Fitur
- Input jumlah uang bulanan
- Pencatatan pengeluaran harian
- Pengelompokan pengeluaran berdasarkan kategori
- Perhitungan total pengeluaran
- Perhitungan sisa uang bulanan
- Ringkasan kondisi keuangan mahasiswa
- Antarmuka sederhana dan mudah digunakan

Cara Menjalankan Aplikasi
- Pastikan Node.js dan npm sudah terpasang di komputer.
- Unduh atau clone repository project ini.
- Buka Command Prompt atau terminal.
- Masuk ke folder project yang berisi file package.json.
- Jalankan perintah npm install untuk menginstal seluruh dependency.
- Setelah proses instalasi selesai, jalankan perintah npm start.
- Aplikasi akan berjalan dan dapat diakses melalui browser sesuai konfigurasi project.
